## ⚡ Escolha pelo seu Perfil

```
Sou iniciante e quero começar hoje:
  → Guia 14: Obsidian + ChatGPT (zero código)
  → Guia 15 Opção A: Mem0 Cloud (10 minutos)

Uso Claude Code e quero memória automática:
  → Guia 16: claude-mem (5 minutos, 1 comando)

Quero algo simples e local em Python:
  → Guia 17: Memoripy (pip install, offline com Ollama)
  → Guia 18: Memvid (ideal para indexar documentos)

Estou construindo um app com LangChain:
  → Guia 20: LangMem (integração nativa)

Preciso de memória para produção/enterprise:
  → Guia 21: Zep (temporal, SOC 2, sub-200ms)

Quero grafos de conhecimento:
  → Guia 19: Cognee (mais simples, MCP nativo)
  → Guia 23: Graphiti (mais poderoso, temporal)

Quero agentes verdadeiramente autônomos:
  → Guia 22: Letta (contexto ilimitado, auto-aprendizado)

Quero reduzir custos de API:
  → Guia 24: Otimização de Tokens (estratégias práticas)
```

---

## 📖 Como usar estes guias

Cada guia segue o mesmo formato:
1. **O que você vai conseguir** — resultados esperados
2. **Pré-requisitos** — o que precisa ter instalado
3. **Opções de instalação** — do mais fácil ao mais completo
4. **Exemplos práticos** — código pronto para copiar e colar
5. **Workflows** — casos de uso do dia a dia
6. **Dicas de otimização** — como economizar tokens e melhorar performance
