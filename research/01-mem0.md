## 📋 Summary

Mem0 is the most popular standalone LLM memory framework as of 2026. It provides an intelligent, self-managing memory layer that automatically extracts, stores, retrieves, and updates memories from LLM conversations. It supports both a self-hosted open-source mode and a managed cloud service.

## 🏗️ Architecture

Mem0 uses a **multi-layer hybrid memory architecture**:

```
Input (conversation / document)
        │
        ▼
  Memory Extractor (LLM)
        │
  ┌─────┴──────┐
  │            │
Vector Store  Graph Store (optional)
(semantic     (relationship
 search)       tracking)
  │            │
  └─────┬──────┘
        │
  Memory Retriever
        │
        ▼
  Context-enriched Response
```

**Storage backends supported:**
- Vector: Qdrant, Pinecone, Weaviate, Chroma, pgvector
- Graph: Neo4j, FalkorDB
- Key-value: Redis (metadata)

## 🚀 Installation & Setup

### For Technical Users

```bash
# Install via pip
pip install mem0ai

# Or with extras
pip install "mem0ai[graph]"   # with graph support
pip install "mem0ai[qdrant]"  # with Qdrant backend
```

### Minimal Example

```python
from mem0 import Memory

# Initialize with default config (uses OpenAI + in-memory)
m = Memory()

# Store a memory
result = m.add("Alice loves hiking and dislikes crowds.", user_id="alice")

# Search memory
memories = m.search("What does Alice enjoy doing?", user_id="alice")
for mem in memories:
    print(mem["memory"])  # "Alice loves hiking and dislikes crowds."

# Update memory (auto-detected on re-add)
m.add("Alice moved to Colorado last year.", user_id="alice")

# Get all memories for a user
all_memories = m.get_all(user_id="alice")
```

### With Custom Config

```python
from mem0 import Memory

config = {
    "vector_store": {
        "provider": "qdrant",
        "config": {
            "collection_name": "my_memories",
            "host": "localhost",
            "port": 6333,
        }
    },
    "llm": {
        "provider": "anthropic",
        "config": {
            "model": "claude-3-5-sonnet-20241022",
            "api_key": "your-api-key"
        }
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small"
        }
    }
}

m = Memory.from_config(config)
```

### Cloud Version (Non-Technical Friendly)

```python
from mem0 import MemoryClient

# Uses managed cloud — no infrastructure setup
client = MemoryClient(api_key="your-mem0-api-key")

client.add("I prefer dark mode and TypeScript.", user_id="user-123")
results = client.search("coding preferences", user_id="user-123")
```

## ✅ Pros

- Largest community; most integrations
- Best token efficiency (~91% fewer tokens than full context)
- Auto-extracts and deduplicates memories without manual tagging
- Cloud option requires zero infrastructure
- Excellent documentation and examples
- Supports multi-user and multi-agent namespacing
- Memory versioning and conflict resolution built-in

## ❌ Cons

- Temporal fact modeling is limited (no validity windows / fact supersession)
- Multi-agent shared memory requires custom implementation
- LongMemEval temporal tasks: 15-point gap vs Zep
- Cloud version has pricing at scale
- Graph support is optional add-on, not default
